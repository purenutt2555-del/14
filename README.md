# ระบบประเมินผลการฝึก — กรมพระธรรมนูญ (ต้นแบบ)

## ไฟล์ในโปรเจกต์
- `index.html` — หน้าเว็บไซต์และส่วนต่าง ๆ
- `style.css` — รูปแบบ สี และการรองรับมือถือ
- `script.js` — บันทึกข้อมูล คำนวณคะแนน รายงาน CSV และสำรองข้อมูล JSON

## เปิดใช้ด้วย GitHub Pages
1. สร้าง repository ใหม่ใน GitHub เช่น `legal-training-evaluation`
2. ตั้ง repository เป็น Public (ถ้าต้องการเผยแพร่ผ่าน GitHub Pages)
3. เข้า repository > Add file > Create new file
4. สร้าง `index.html` วางเนื้อหาจากไฟล์ `index.html` แล้ว Commit changes
5. ทำซ้ำเพื่อสร้าง `style.css` และ `script.js` โดยวางเนื้อหาของแต่ละไฟล์
6. เข้า Settings > Pages
7. ใน Build and deployment เลือก Deploy from a branch
8. เลือก Branch `main` และ folder `/(root)` แล้วกด Save
9. รอสักครู่ เปิด URL ที่ GitHub Pages แสดงให้

## ข้อจำกัดและความปลอดภัย
- รุ่นนี้เก็บข้อมูลใน `localStorage` ของเบราว์เซอร์ ข้อมูลไม่ได้แชร์ข้ามเครื่องหรือข้ามผู้ใช้ และอาจหายได้หากล้างข้อมูลเว็บไซต์
- ใช้ข้อมูลสมมติในการทดลอง ห้ามใส่ข้อมูลส่วนบุคคลหรือข้อมูลราชการที่เป็นความลับ
- การเผยแพร่หน้าเว็บเป็นสาธารณะไม่ได้ทำให้ข้อมูลที่บันทึกในเบราว์เซอร์เป็นฐานข้อมูลกลาง
- ก่อนใช้งานจริงต้องเพิ่มระบบล็อกอิน การกำหนดสิทธิ์ และฐานข้อมูลที่ปลอดภัย รวมทั้งตรวจสอบเกณฑ์คะแนนกับหน่วยงาน
- ผลประเมิน 80–100 = ดีมาก, 60–79 = ผ่านเกณฑ์, ต่ำกว่า 60 = ควรติดตาม เป็นค่าเริ่มต้นตัวอย่าง ปรับตามเกณฑ์จริงได้ใน `script.js`
